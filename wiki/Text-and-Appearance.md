# Text & Appearance

These settings live on the **Text** tab of the settings panel. They control how the words look. The tab
has two columns: the **quote** (the verse text) on the left, and the **reference** (the small line
underneath) on the right. Both have the same set of controls, so you can style each one independently.

## Font (typeface)

- Click the **font name** to open a curated list of good-looking fonts and pick one.
- Prefer a specific font that is not in the list? Use the **type a font name** box and enter it exactly
  as it appears in Windows (for example `Times New Roman`).

Defaults: the quote uses **Calibri**, the reference uses **Segoe UI**.

> **Note:** The font you choose must actually contain the characters being shown. For English any normal
> font is fine. For Arabic or other scripts, pick a font that supports that script (see
> **[Languages](Languages)**).

## Size

Drag the **size slider** (or scroll over it) to make the text bigger or smaller. The quote and reference
have separate sliders.

## Style

Three buttons let you pick **Bold**, **Regular**, or **Italic**. The default is Regular.

## Colour

Each colour picker has:

- A **preview swatch** so you can see the colour.
- Four sliders: **Red**, **Green**, **Blue**, and **Alpha** (transparency, where lower is more
  see-through).
- Boxes to type exact numbers if you prefer.

Set the quote and reference to whatever colours suit your wallpaper.

## Drop shadow (quote only)

A drop shadow makes the verse easier to read on busy or light wallpapers.

- Tick the **drop shadow** checkbox under the quote column to turn it on.
- Use the **shadow colour picker** (Red / Green / Blue / Alpha) to choose the shadow colour. Black is a
  classic choice.
- Use the two **offset sliders** (X and Y) to move the shadow left/right and up/down. A small offset like
  2, 2 gives a subtle lift; larger values give a bolder look. Negative values shift the shadow up and to
  the left.

Defaults: the shadow is **off**, black, with a 2, 2 offset.

> **Good to know:** The shadow cannot be blurred or softened, only moved and coloured. This is a
> limitation of how Rainmeter draws text, not the skin. Only the offset and colour are offered because
> those are the parts that can actually change.
