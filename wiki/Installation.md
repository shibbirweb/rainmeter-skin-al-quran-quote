# Installation

Al-Quran Quote runs on top of **Rainmeter**, a free app that displays widgets ("skins") on your Windows
desktop. So there are two small steps: install Rainmeter, then install this skin.

## Step 1 - Install Rainmeter (once)

If you do not already have Rainmeter:

1. Go to **[rainmeter.net](https://www.rainmeter.net)** and download it.
2. Run the installer and accept the defaults.
3. Rainmeter starts automatically and adds an icon to your system tray (the little arrows near the clock).

Rainmeter is safe, popular, and open source. You only ever install it once.

## Step 2 - Install Al-Quran Quote (the easy way)

This is the recommended way for almost everyone.

1. Open the **[Releases page](https://github.com/shibbirweb/rainmeter-skin-al-quran-quote/releases)**.
2. Download the file that ends in **`.rmskin`** (for example `AlQuranQuote_1.0.0.rmskin`).
3. **Double-click** the downloaded file. Rainmeter opens a small installer window.
4. Click **Install**.

That's it. The verse panel appears on your desktop. You can drag it wherever you like.

> **Tip:** A `.rmskin` file is the official "one-click" installer format for Rainmeter skins. When you
> update to a newer version later, your personal settings (fonts, colours, size) are kept.

## Step 2 (alternative) - Manual install

Only needed if you downloaded the source code instead of the `.rmskin` file:

1. Make sure Rainmeter is installed (Step 1).
2. Copy the folder `Skins/AlQuranQuote` from the download into your Rainmeter skins folder, usually:
   `Documents\Rainmeter\Skins\`
3. Open Rainmeter, click **Refresh all**.
4. Find **AlQuranQuote** in the list, expand it, and load **`AlQuranQuote.ini`**.

## Moving and positioning the panel

- **Move it:** click and drag the panel anywhere on the desktop.
- **Keep it in place:** right-click the panel, then use Rainmeter's menu to lock its position if you wish.

## Uninstalling

1. Right-click the panel and choose **Unload skin** to hide it.
2. To remove it completely, open Rainmeter, right-click **AlQuranQuote**, and delete the skin, or delete
   the `AlQuranQuote` folder from your skins folder.
