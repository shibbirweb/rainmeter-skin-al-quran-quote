# Multiple Windows

You can show more than one verse panel at the same time, up to **8**. This is perfect if you have several
monitors and want a verse on each, but you can also use it on a single screen.

Each window is fully independent: its own verse, its own fonts, colours, size, and position.

## Adding or removing windows

1. Open the settings panel and go to the **Panel** tab.
2. Find the **Quote windows** control.
3. Use the **+** and **-** buttons to increase or decrease the number of windows.

- Increasing the number makes a new panel appear. Drag it to the monitor or spot you want.
- Decreasing the number removes the extra panels.

Your choice is remembered, so the same number of windows returns after a restart.

## Styling each window separately

Every window has its **own settings icon**. Click the settings icon **on the window you want to change**,
and the settings panel controls **that** window. So you can, for example, make the panel on your second
monitor larger or a different colour than the first.

To help you keep track, the window currently being edited shows a small **"editing"** badge, so you always
know which panel the open settings panel is controlling.

## Things that are shared vs. per-window

- **Per window** (independent): fonts, sizes, colours, the shadow, background, width and height, and the
  displayed verse.
- **Shared** across all windows: the reference **label** text and any **custom verse** text.
